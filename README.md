# DSA5 Traveller
DSA5 Modul zur Definition und Verwaltung aktueller Aufenthalts-Orte
- Verwaltet beliebige Regionen-Typen (z.B. politische Karten, landschaftliche Regionen) sowie Biome (z.B. Wald, Wüste, Regenwald, Gebirge...)
- Region wird durch Position des Tokens auf einer Karte automatisch bestimmt
- Kann eigene Zeichnungen einfach als Region parsen
- Unterstützt andere Module dabei, Zufalls-Tabellen die auf Regionen basieren zu erstellen

### Andere Module
- Unterstützt [DSA5 Meistertools](https://github.com/tyr0mancer/dsa5-meistertools)
- Unterstützt [DSA5 Händler und Tavernen](https://github.com/tyr0mancer/dsa5-merchants-taverns)
- Kann mit Inhalten aus eigenen Homebrew Modulen kombiniert werden
